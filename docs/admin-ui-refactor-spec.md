> **定位**：本规范为「既有需求（你提供的全部条目）+ 缺口补全（本次审计新增）」的完整版，可直接作为前端重构实施蓝本与评审基线。

## 0. 总则（设计原则）

【补全】所有 UI 决策遵循 6 条原则，任何页面/组件改动先对照：
1. **轻量克制**：浅色为主、无渐变无炫彩；色彩只表达语义。
2. **高信息密度**：一屏承载更多操作与数据，但保持 8px 网格节奏不乱。
3. **上下文不丢失**：列表滚动位置、筛选条件、操作状态在任何跳转/抽屉/弹窗后保持。
4. **一处定义、全局生效**：视觉令牌（tokens）与组件（admin/common）为唯一事实源。
5. **权限感知**：同一组件在不同角色下自动裁剪，界面不出现"看得到点不了"的按钮。
6. **键盘可达**：所有功能可用鼠标完成，也全部可用键盘完成（见 §9 无障碍）。

## 1. 设计令牌 Design Tokens（`src/theme/tokens.ts` 扩展）

### 1.1 色板 Color【补全完整体系】

【补全】完整色板定义（含浅底/描边/深色各档，供组件直接引用，避免页面再硬编码）：

| 语义 | Token | 主色 | 浅底(10%) | 描边(25%) |
|---|---|---|---|---|
| 品牌 | `primary` | `#1a56db` | `#eff6ff` | `#bfdbfe` |
| 品牌 Hover / Active | `primaryHover / primaryActive` | `#1e40af / #1e3a8a` | — | — |

| 错误 | `error` | `#dc2626` | `#fef2f2` | `#fecaca` |
| 信息 | `info` | `#2563eb` | `#eff6ff` | `#bfdbfe` |
| 中性 | `neutral` | `#6b7280` | `#f9fafb` | `#e5e7eb` |

【补全】功能性颜色：
- 文字：主 `#111827` / 次 `#374151` / 辅助 `#6b7280` / 弱化 `#767676`（AA 4.5:1）/ 反白 `#fff` / 链接 `#1a56db`
- 边框：浅 `#e5e7eb` / 中 `#d1d5db` / 深 `#9ca3af`；分割线统一 `#e5e7eb`
- 背景：页面 `#f9fafb` / 卡片 `#fff` / 操作栏 `#f9fafb` / 条带 `#fafafa` / 遮罩 `rgba(0,0,0,0.35)` / 骨架 `#e5e7eb`
- 禁用：文字 `#9ca3af` / 背景 `#f3f4f6`（禁用按钮/输入不可用态统一走此组合）
- 阴影遮罩：弹窗遮罩 `rgba(0,0,0,0.35)` + `backdrop-filter:blur(2px)`（不支持时退化为纯遮罩，见 §13）
- 选中高亮：列表行选中 `rgba(26,86,219,0.06)`；表格排序激活 `#1a56db`

### 1.2 字体 Typography【补全】
【原需求】标题 20px/600、正文 14px/400、辅助 12px/400、标签 11px/500、行高 1.5。
【补全】完整字体体系：
- 字体族：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`；品牌区保留 `Playfair Display` 衬线（仅 Logo 水印场景）。
- 等宽字体（ID/券码/任务号/单号）：`"SF Mono", "Cascadia Code", Consolas, "Courier New", monospace`，并启用 `font-variant-numeric: tabular-nums`（数字等宽对齐）。
- 字号层级：`xs 11 / sm 12 / base 14 / md 15 / lg 17 / xl 20 / 2xl 24`；字重 400/500/600/700。
- 数字/金额统一 tabular-nums，避免表格列数字跳动。

### 1.3 间距 / 圆角 / 阴影【原需求 + 补全映射表】
- 间距 8px 网格：`xs4 / sm8 / md12 / lg16 / xl20 / 2xl24 / 3xl32 / section40 / page48`；页面内边距 24px（窄屏 16px）、卡片内边距 24px、表单字段垂直间距 16px、按钮组间距 8px、列表行内边距 16px 24px。
- 圆角：**卡片/面板/表格 8px；按钮 4px；标签/徽章 12px；图片 4px；输入框 6px；搜索框 20px（全圆角）**；头像 50%。
- 阴影三级（唯一标准，禁止其他值）：卡片 `0 1px 3px rgba(0,0,0,0.06)`；下拉/抽屉 `0 4px 12px rgba(0,0,0,0.08)`；弹窗 `0 8px 32px rgba(0,0,0,0.12)`。
- 焦点环：`0 0 0 3px rgba(26,86,219,0.25)`（全局 focus-visible 统一）。

### 1.4 动效 Motion【补全】
- 基础过渡：`all 0.2s ease`（按钮/链接/卡片行/徽章）；激活按下 `scale(0.98)`。
- 抽屉滑入：`transform translateX(100%→0)`，0.28s cubic-bezier(0.4,0,0.2,1)；关闭反向。
- 弹窗：淡入 + 轻微上移 8px，0.2s。
- Toast：顶部淡入下滑 0.2s；自动消失 3s。
- 骨架扫光：`@keyframes shimmer`（左→右），背景 `linear-gradient(90deg,#e5e7eb 25%,#f3f4f6 37%,#e5e7eb 63%)`，`background-size:400% 100%`，1.4s 无限。
- 进度条填充：width 0.6s ease。
- 尊重系统 `prefers-reduced-motion`：关闭非必要动画（见 §9）。

### 1.5 断点 Breakpoints 与行为【补全】
| 断点 | 行为 |
|---|---|
| ≥1280（默认桌面） | 三栏完整布局，主:辅 7:3 |
| <1366 | 侧边栏自动折叠为 64px（现状保留） |
| 1024–1280 | 辅助面板可手动收起；表格列减少（隐藏低频列） |

| <768 | 内容区内边距降为 16px；表格横向滚动；多列筛选折叠为「筛选」按钮展开 |

> 【补全】明确本轮只做 768px 以上桌面优化；移动端完整适配列为后续迭代（与现状一致，不扩scope）。

### 1.6 Z 轴管理 `src/theme/zIndex.ts`【原需求 + 冲突修正】
【原需求】常量：`drawer:1000, modal:1100, dropdown:1200, toast:1300, loading:1400`。
【冲突修正】你前文写"所有弹窗 z-index:1000"，与 zIndex.ts 的 `modal:1100` 矛盾。**统一采用 zIndex.ts**：Modal=1100、Drawer=1000（Drawer 常与页面共存、不遮 Modal）、Dropdown=1200、Toast=1300、全局 Loading=1400、ReauthModal=1500（会话层最高）。
【补全】使用规则：任何浮层禁止写死数字，一律 `import { ZIndex } from '../../theme/zIndex'`；新浮层先在文件登记层级再使用。现有散落的 `1000/1050/1100/100/60/10` 全部迁移至本表。

### 1.7 图标 Icon【补全】
- 统一线性图标（1.5px stroke）SVG 组件集；尺寸：菜单 24 / 按钮 16 / 行内 14 / 大图 32。
- 图标状态：默认 `#6b7280`、hover/激活 `#1a56db`、危险 `#dc2626`、禁用 `#d1d5db`。
- 旋转加载图标统一 `SpinIcon`（逆时针 0.8s 旋转）；加载中按钮图标切换为 spinner。
- 现有 `Icon` 组件扩展现有 name 集合，不另起体系。

## 2. 全局框架

### 2.1 布局总纲：左定右动、三栏分层【原需求】
```
┌────────────┬──────────────────────────────────────────────────────┐
│            │ Header（56px，sticky top:0）                          │
│ 侧边栏     ├──────────────────────────────────────────────────────┤
│ 220/64px   │ 上下文操作栏 Contextual Action Bar（浅灰 #f9fafb）     │
│ sticky     ├──────────────────────────────┬───────────────────────┤
│ top:0      │ 主内容区（flex:1）           │ 辅助面板（Drawer）     │
│ height:100vh│ 列表/表单/看板（内部滚动）   │ 400–480px，右侧滑入    │
│ overflow-y:│ （占 7 份）                  │ （占 3 份，可收起）    │
│ auto       │                              │ 不遮挡侧边栏与主操作   │
└────────────┴──────────────────────────────┴───────────────────────┘
```
- 侧边栏：`position:sticky; top:0; height:100vh; overflow-y:auto`，与右侧独立滚动容器。
- 内容区：主内容 + 辅助面板 7:3；辅助面板以 `Drawer` 组件从右滑入（见 §3.11），**不遮挡左侧导航、不遮盖主内容区关键操作按钮**；关闭时主内容平滑回填。

### 2.2 左侧导航（5 分组不变）【原需求 + 补全】
- 尺寸：220px / 折叠 64px；深色底 `#1a1a2e`；`position:sticky;top:0;height:100vh;overflow-y:auto`；滚动条细窄（6px、圆角、半透明）。
- 5 分组顺序不变：商品运营 / 履约 / 沟通 / 营销 / 系统管理；分组标题 11px 大写、`#a0aec0`、留白 12px 16px 4px。
- **菜单项重排（常用优先、低频下沉）**：每组内按操作频率排序——
  - 商品运营：商品 → 分类 → 品牌 → 标签
  - 履约：订单
  - 沟通：客服会话 → 通知 → 申请单
  - 营销：营销券 → 活动
  - 系统管理：用户组 → RBAC → 审计日志 → 邮件模板 → 异步任务 → 回收站（低频沉底）
- **双行布局**：图标 24px 居中（行高 36px）+ 文字 14px 居下（行高 18px），两行间距 2px，整体菜单项 padding 10px 12px。
- 激活态：左侧 3px 蓝条 + 背景 `rgba(26,86,219,0.08)` + 文字白；悬停态仅背景 `rgba(0,0,0,0.04)`，不引入额外颜色。
- **取消所有菜单项红点/角标**（现状聊天未读红点移除）；未读数统一聚合到 Header 通知铃（见 §2.3）。
- 折叠态：仅显示 24px 图标居中 + title 提示；折叠按钮（chevron 旋转）置于底部，`localStorage('admin_sidebar_collapsed')` 持久化；<1366px 自动折叠（现状保留）。
- RBAC 裁剪：`useAllowedMenuPaths()` 过滤 + 空分组隐藏（现状保留，见 §6）。

### 2.3 Header（56px）【原需求 + 补全】
- 白底 + 底部 1px `#e5e7eb` 分割线；`position:sticky;top:0;z-index:ZIndex.header(900)`；左右结构。
- 从左至右：**面包屑**（首页 › 当前模块 › 子页面，灰色小字 12px，`›` 箭头分隔；末级高亮 `#111827`；非末级 hover 变蓝可点跳转）→ **中间留白（flex:1）** → **全局搜索框**（240px、圆角 20px、左侧放大镜图标、占位"搜索订单/商品/用户…"；聚焦蓝色焦点环；`Ctrl+K` 聚焦、`Esc` 失焦；输入 ≥2 字符 300ms 防抖出下拉结果（按模块分组：商品/订单/用户/券，最多各 5 条，Enter 跳转第一条，↑↓ 选择））→ **语言切换**（文字按钮"中/EN"，悬停浅蓝）→ **通知铃**（未读红点 ≤99+；点击下拉**最近 5 条**、按类型分组（系统/订单/营销/客服/操作），点击跳转对应页或标记已读，底部"查看全部"→ `/admin/notifications`；下拉 320px、阴影三级、`dropdown:1200`）→ **用户头像**（40px 圆形，无头像显示首字母；悬停/点击下拉：用户名 + 角色标签（超管/组长/成员）+ 退出登录；登出 fire-and-forget 失效 token 后跳 `/admin/login`）。
- 通知铃数据：进页拉取 + 60s 轮询（保留现状节奏）；实时性后续可切 WS。

### 2.4 上下文操作栏 Contextual Action Bar【原需求 + 补全】
- 位于 Header 之下、与页面内容同宽；背景 `#f9fafb`；内边距 `12px 24px`；底部 1px `#e5e7eb`；`sticky top:56px; z-index:ZIndex.header(900)`（列表滚动时操作栏保持可见）。
- 结构：**左：模块主按钮组**（按角色裁剪）；**右：辅助入口**（最近更新 / 帮助文档 / 刷新）。
- 各模块按钮清单（【补全】明细，均按 §6 角色裁剪）：
  - 商品：新建商品 / 批量导入 / 回收站（左）；最近更新、帮助文档（右）
  - 订单：刷新（左）；帮助文档（右）
  - 营销券：新建优惠券（左）；帮助文档（右）
  - 客服：刷新（左）；帮助文档（右）
  - 系统管理：创建管理员（RBAC 页，左）；帮助文档（右）

### 2.5 主内容 + 辅助面板（7:3）【原需求 + 补全】
- 主内容：`flex:1; min-width:0`，白卡片承载列表/表单；卡片内列表区域**固定高度 + 内部滚动**（`max-height` + `overflow-y:auto`，表头 sticky），筛选/分页/Tab 变化只刷新内容、保持滚动位置与操作上下文。
- 辅助面板 = `Drawer`（§3.11）：宽 400–480px（列表详情 480px、编辑表单 400px、角色抽屉 360px 例外）；从右滑入；带遮罩层（点击关闭）与细腻阴影；**不遮挡侧边栏、不遮盖主内容区关键操作按钮**；关闭后主内容平滑回填。

### 2.6 底部状态栏【补全】
- 本轮不引入全局底部状态栏（沿用现状）；如需全局任务/系统健康状态，统一由 Header 通知铃聚合承载，避免新增常驻 UI 抢占信息密度。

## 3. 组件体系（`components/admin/common` 按类型分文件）

【原需求】按文件管理：`Button/Input/Modal/Table/Drawer/Upload/Skeleton/Empty/ErrorBoundary/Toast`；完整 TS 类型 + Props 注释；支持 `className` 透传与 `style` 覆盖；修改根组件即全局生效。
【补全】在上述 10 个文件外补充：`Select/DatePicker/Switch/Radio/Checkbox/Tag/Badge/Avatar/Pagination/FilterBar/Form/StepModal/ConfirmDialog/Popconfirm/Tabs/Menu/Breadcrumb/Dropdown/Tooltip/Progress/Descriptions/Result/StatusBadge/Icon`。所有组件统一导出自 `index.ts`，内部用 tokens + zIndex，禁止页面内再定义重复样式。

### 3.1 Button
- 变体：`primary`（实心蓝）/ `secondary`（描边灰）/ `danger`（红描边 hover 红填充）/ `success`（绿描边 hover 绿填充）/ `ghost`（透明）/ `link`（文字链接）；新增 `danger-solid`（实心红，用于高危确认）。
- 尺寸：`lg 40px / md 36px / sm 32px / xs 24px`；图标+文字组合 8px 间距。
- 状态：默认/hover（同色加深或反白）/**按下 `scale(0.98)`**/disabled（`opacity:.6`+not-allowed）/loading（图标转 spinner + 文案可选"处理中…"，disabled）。
- 属性：`variant/size/loading/disabled/icon/iconPosition/block/type(button|submit|reset)/autoFocus/aria-label`。

### 3.2 Input / InputNumber / TextArea / SearchBox
- Input：高 38px（compact 32px）；focus 蓝边框+焦点环；`type=text|number|password|email`；密码框带可见切换（eye 图标）；金额输入用 InputNumber（千分位、允许小数 2 位、min/max、步进）。
- 清空按钮：可输入内容时右侧显示 ✕（hover 变红）。
- TextArea：min 3 行 / max 10 行自适应；字数统计（可选）；错误态红边框+ErrorText。
- SearchBox：即 §2.3 全局搜索的下拉实现，可复用于页面级搜索。

### 3.3 Select（含多选/搜索/级联）
- 单选下拉：高 32px；选项 hover 浅蓝、选中打勾；支持清空（✕）、禁用项置灰。
- 多选：选中项以 Tag（可移除 ✕）回显；支持全选/清空。
- 搜索下拉：内置输入过滤（300ms 防抖）；远端搜索 loading。
- 级联：分类/品牌/管理组选择用级联或树形 Select（缩进层级，沿用现状 L1-L3 扁平化+缩进）。
- 空选项：显示"无匹配选项"（非空白）。

### 3.4 DatePicker / DateRangePicker
- 原生 `datetime-local`（现状）升级为统一封装：面板月历、快捷项（今天/最近7天/最近30天/本月）、清空；有效期等区间字段用 RangePicker；时区统一服务器 UTC，前端本地化显示（见 §10）。

### 3.5 Switch / Radio / Checkbox / Toggle
- Switch：主蓝轨道+白色滑块，disabled 灰；用于启用/可叠加/track_inventory/Active。
- Radio/Checkbox：统一描边灰→选中蓝；Checkbox 全选态含"半选"（indeterminate，表格批量选择必需）。

### 3.6 Tag / Badge / StatusBadge / Avatar
- Tag：圆角 12px、高 22px、字号 12px；语义色（§1.1 浅底+主色字）；可关闭 ✕；可点（标签筛选）。
- Badge：数字角标，上限 `99+`；红点模式（无数字）；挂载于铃铛/图标右上。
- StatusBadge：沿用 §4.7 现状映射，全部迁至语义色板。
- Avatar：圆形 40px；无图显示首字母（用户名首字符大写）；可挂在线/离线点。

### 3.7 Table【原需求 + 补全细节】
- 基础：白卡、圆角 8px、表头 11px 大写灰（Lumiere 风格保留）、行高默认 48px（订单页 64px 为业务定制）。
- **列能力**：`width/sortable/sortOrder/fixed(左/右)/ellipsis+tooltip/hidden`；**操作列固定右侧**（sticky right + 左阴影分隔）；长列表**表头 sticky**。
- **排序**：点击表头循环 升序→降序→取消；指示箭头 ▲▼；多列排序（后点优先，可配 maxSortCount）。
- **行选择**：首列 Checkbox；表头全选含半选；选中行浅蓝底；批量工具条随选中浮现（顶部，含 N 条选中 + 取消 + 操作按钮）。
- **密度**：`size=standard|compact`（compact 行高 40px、字号 13px）；订单页固定 64px。
- 空/载/错：四态内置（Skeleton/Empty/Error+Retry/Data）——沿用 DataTable 现状，统一样式。
- 性能：大数据量（>200 行）启用**虚拟滚动**（`react-window` 或等能力）；行组件 memo；图片列懒加载。
- 单元格：数字右对齐（金额/数量）、ID/券码等宽字体、长文本 ellipsis + title。

### 3.8 Pagination
- 样式：右对齐、页码按钮（激活红底——**统一迁至主蓝**，见 §13 不一致修复）、首尾+省略、前后箭头、"共 N 条"。
- 增强【补全】：**每页条数选择**（20/50/100，默认 20）；跳页输入（回车）；总数展示含"第 x-y 条，共 n 条"。
- 单页隐藏（现状）；服务端分页 + 筛选/搜索变更重置页码 1（现状）。

### 3.9 Modal【原需求 + 补全】
- 尺寸：表单类 max 720px；列表/详情类 max 960px；高度 ≤85vh；`position:fixed` 居中于视口（页面滚动不带动弹窗）；`z-index:ZIndex.modal(1100)`。
- 结构：顶部固定标题栏（标题 + 关闭 X，24px 命中区）；中间内容 `overflow-y:auto` 独立滚动；底部固定操作栏（取消/确认，右对齐，间距 8px）。
- 遮罩：`rgba(0,0,0,0.35)` + `backdrop-filter:blur(2px)`（降级纯色）；点击遮罩是否关闭按场景：表单类默认不关（防误触丢内容，沿用现状 FormDialog 行为）、确认类默认关闭。
- 行为：打开动画淡入上移；Esc 关闭（确认弹窗）；打开时焦点入弹窗、关闭还原（§9）；body 滚动锁定（`overflow:hidden`）。
- Props：`open/title/width/height/mask/maskClosable/footer/onCancel/onOk/confirmLoading/destroyOnClose`。

### 3.10 StepModal（步骤条弹窗）【原需求 + 补全】
- 顶部步骤条：圆点+连线（完成=实心蓝+对勾；当前=实心蓝描边；未到=灰点）；标签（第1步/第2步/第3步）；"1/3"计数。
- 底部按钮随步骤：第 1 步仅「下一步」；中间「上一步/下一步」；最后「上一步/提交」（提交 loading）。
- 每步内容区独立 `overflow-y:auto`，弹窗高度不变（≤85vh）；步骤内校验通过才可下一步；离开步骤保留已填值。
- 适用：商品审核（审阅→意见→提交）、活动配置（基本信息→规则→SKU 关联）、批量导入确认（预览→确认→结果）。
- 属性：`steps:{title,content}[], current, onNext/onPrev/onFinish, finishLabel, loading`。

### 3.11 Drawer（辅助面板）【原需求 + 补全】
- 位置：右侧滑入；宽度 400–480px（角色抽屉 360px 例外；<1024px 全屏）；`position:fixed; top:0; right:0; height:100vh; z-index:ZIndex.drawer(1000)`。
- 动画：`translateX(100%→0)` 0.28s；关闭反向 + 主内容回填过渡。
- 遮罩：点击关闭（可选 `maskClosable`）；Esc 关闭；**不遮挡左侧导航**（Drawer 仅覆盖内容区右侧，或遮罩仅至内容区边界——实现上可用 `right: 0` + 遮罩层级在侧边栏之下）。
- 头部：标题 + 关闭 X；正文滚动；底部可选操作栏（编辑保存）。
- 用途：订单详情（状态时间线+明细+物流+售后入口）、商品详情/编辑、券详情、角色编辑（360px）。
- 与列表联动【补全】：打开时记录列表滚动位置，关闭后恢复（不重置页码/筛选）；抽屉内编辑保存成功后**行级刷新**（更新该行而非整表重载）。

### 3.12 Upload（统一图片上传组件）【原需求 + 补全】
- 上传区：虚线边框矩形、宽 100% × 高 200px、背景 `#fafafa`、圆角 8px；中央"拖拽图片至此或点击上传"灰字 + 上传图标；拖拽悬停：边框变蓝 + 背景浅蓝（`#eff6ff`）。
- 触发：点击弹系统文件选择器；支持多选（Ctrl/Shift 批量）；`accept="image/*"`。
- 文件卡片：高 72px、间距 8px、横向；含缩略图（48×48、圆角 4px）+ 文件名 + **底部进度条（2px 高、蓝填充、带百分比数字）** + 移除 X。
- 上传完成：缩略图固定、背景转纯白；移除 X 变**垃圾桶图标（hover 变红）**。
- **拖拽排序**：`react-dnd` 调整顺序；**主图**：左上角星标（点击切换，金色 `#f59e0b` 实心/空心）。
- 前端压缩：上传前转 **WebP（质量 0.8）**，长边 ≤2048px，单文件 ≤5MB，超限前端拒绝并提示（文件名+原因）。
- 失败态：卡片红边框 + 重试按钮；成功态显示绿色对勾。
- 现状 `MediaManager` 四尺寸（thumb/list/large/original）上传逻辑保留，UI 层统一换用本组件。

### 3.13 Skeleton【原需求 + 补全】
- 类型：`table`（表头+行×5）/ `card`（列表卡片行）/ `avatar`（圆形）/ `text`（多行）/ `image`（上传/详情大图）。
- 颜色 `#e5e7eb`，shimmer 扫光动画（§1.4）；可配 `rows/cols`。
- 适用：所有异步首载（列表/详情/下拉/抽屉），替换现有转菊花。

### 3.14 Empty / ErrorState / ErrorBoundary / LoadingState【补全】
- Empty：无数据（图标+文案+可选引导按钮）/ 无搜索结果（提示换关键词）/ 无权限（403 提示）；居中于固定高度容器。
- ErrorState：请求失败（图标+错误文案+「重试」按钮）；404（页面级，返回列表）；500（服务端错误 + 联系运维）。
- ErrorBoundary：渲染异常兜底（组件级错误卡片 + 重载），不白屏；全局一层 + 每 Tab 一层。
- LoadingState：全屏/局部 loading 覆盖层（z-index 1400），用于提交等同步阻塞操作。

### 3.15 Toast【补全完整规范】
- 位置：顶部居中（现状页内顶部保留为兼容，新实现统一全局队列）；`z-index:ZIndex.toast(1300)`。
- 四态：success/error/warning/info，各带图标与语义色。
- 时长：3s 自动消失（error 5s）；支持手动关闭 ✕；多条队列堆叠（间距 8px，最多同时 5 条）。
- API：`toast.success(msg)/error/warning/info`（Context 或 event 总线，脱离页面内 state）。

### 3.16 ConfirmDialog / Popconfirm【补全】
- ConfirmDialog：沿用规格（§4.6 现状）升级遮罩/圆角/阴影至新标准；危险操作确认按钮 `danger-solid`。
- Popconfirm：轻量气泡确认（删除行/单项操作），出现在触发元素旁（`dropdown:1200`），含取消/确认；用于替代部分 Modal 场景（减少弹窗打断）。

### 3.17 Form【补全】
- 布局：单列（默认）/ 两列栅格（`grid-template-columns:repeat(2,1fr)`，<1024 降单列）；label 右对齐（宽 96px）或上置（宽 100%）。
- 必填：label 前红 `*`；校验时机：blur + submit（输入中不即时报错，减少打扰）；错误：字段下方 ErrorText + 红边框，提交时滚动至首个错误。
- 提交：按钮 loading；成功后 Toast + 按场景跳转/重置/关抽屉；失败保留已填值。
- 分组：表单分区标题（16px/600）+ 分割线；字段间距 16px。

### 3.18 FilterBar【补全】
- 组成：搜索框 + 状态/类型/渠道下拉 + 日期区间 + 「搜索/重置」按钮。
- **条件持久化**：筛选条件同步 URL query（`useSearchParams`），刷新/分享保留；可选 `localStorage` 记住上次条件。
- **已选条件 chip**：当筛选 >1 时展示已选标签（可单个 ✕ 移除、一键清空）。
- 变更行为：下拉/输入变更即查（300ms 防抖），重置页码 1（现状）。

### 3.19 Tabs / Menu / Breadcrumb / Dropdown / Tooltip【补全】
- Tabs：下划线式（激活蓝下划线+文字加粗），用于订单/售后、RBAC/用户等 Tab 场景；可带 count 徽章。
- Breadcrumb：§2.3 规格；可复用为页内（PageHeader 下）。
- Dropdown：菜单下拉（用户菜单/通知/行内更多"⋯"）；`dropdown:1200`；选项 hover 浅蓝、危险项红字。
- Tooltip：统一轻量气泡（深色底白字，圆角 4px，字号 12px）；用于截断文本/图标释义；hover 0.3s 延迟出现。

### 3.20 Progress / Spin【补全】
- Progress：线型（2px/6px/8px 高可选，蓝/红语义填充，width 0.6s 过渡，百分比文字可选，sticky 合计行等）；圆型（少用）。
- Spin：按钮内 14px、块级 24px；替代全局转菊花场景（骨架优先）。

### 3.21 其他【补全】
- Divider（水平/垂直，`#e5e7eb`）；Collapse（活动配置折叠）；Descriptions（订单/券详情只读字段，2 列栅格）；Result（403/404/500 页模板）；ImageCropper（头像裁剪，现状保留）；NotificationFloat（废弃）。

## 4. 页面模板（统一模式）

【原需求】每个子系统：顶部模块上下文操作栏（主按钮/筛选/搜索/视图切换）+ 中部主列表/看板 + 右侧辅助面板。
【补全】6 种标准模板：
1. **列表页模板**：操作栏 + FilterBar + 固定高度列表（Table/卡片行）+ 分页 + 行操作（编辑/状态操作/更多）+ 详情 Drawer。
2. **表单页模板**（商品新建/编辑）：操作栏（返回/保存草稿/保存并提交）+ 左侧 sticky 分节导航 + 主表单 + 底部固定操作条（沿用现状 4 分区，视觉升级）。
3. **详情抽屉模板**：Descriptions + 状态时间线 + 关联列表（商品明细/物流/售后入口）+ 底部操作。
4. **看板模板**（营销/任务）：统计区（数字卡片或表格合计）+ 列表 + 进度。
5. **客服双栏模板**：左 280px 联系人列表 + 右聊天区（§5.4）。
6. **系统配置模板**：左树右内容（分类/用户组/RBAC 矩阵）或全表单（审计/任务/邮件模板）。

## 6. 角色与权限裁剪（矩阵）

【原需求】基于后端 `scope_orders` 与 `useAllowedMenuPaths` 自动裁剪；页面标题与操作栏不变，列数与按钮按权限动态减少。
【补全】四角色完整裁剪矩阵（前后端双校验）：

| 能力 | 超级管理员 | 组长 | 普通管理员（组员） | 客服 |
|---|---|---|---|---|
| 菜单可见 | 全部 | 除系统管理-品牌/标签/回收站外的全部 | 商品/订单/营销/沟通（无系统管理） | 仅沟通（会话/通知） |
| 商品 | 全部列+全部操作（含删除/迁移/审核） | 本组商品；无品牌/标签写操作、无删除/迁移 | 仅 `created_by`/`group_id` 内商品；隐藏删除/迁移/审核/上架 | — |
| 订单 | 全部 | 本组范围（scope_orders） | 仅参与订单 | — |
| 营销券 | 全部（含删除/审核） | 本组券（创建/编辑/推广码；无删除） | 无入口或只读 | — |
| 客服 | 全部 | 本组会话（强制接手） | 被分配会话 | 仅会话/通知 |
| 按钮裁剪 | 全量 | 隐藏全局配置类按钮 | 隐藏删除/迁移/审核/批量 | 隐藏一切业务操作 |
| 行级过滤 | 无过滤 | `group_id` 限制 | `created_by`/`group_id` 限制 | 会话 owner |

- 实现：`usePermission('goods.delete')` 等 hook 驱动按钮条件渲染；菜单用 `useAllowedMenuPaths`；后端二次校验（403 兜底）；**无权限的直接 URL 访问 → 403 Result 页**。
- 前端反馈：按钮隐藏而非禁用（禁用+tooltip 仅用于"状态不允许"而非"无权限"）；列表上方不加权限提示条（界面保持干净）。
- 跨角色一致性：进入同一页，标题/操作栏骨架一致，仅列数与按钮差异（符合大厂"视图一致、能力分级"惯例）。

## 7. 数据展示与格式化规范【补全】

1. **金额**：币种符号 ¥（CNY）前缀、千分位、两位小数；0 显示 `¥0.00`；空值 `-`；负退款红字。
2. **日期时间**：列表用相对时间（刚刚/5 分钟前/今天 14:30/昨天/8 月 21 日）；详情用绝对时间（`2026-08-21 14:30:00`，本地时区）；均 `tabular-nums`。
3. **数字对齐**：金额/数量/进度列右对齐；ID/单号/券码/account_no 等宽字体 + 可选复制按钮。
4. **长文本**：单行/两行 ellipsis + Tooltip；描述类换行 `pre-wrap`。
5. **空值**：统一 `-`（不显示 null/undefined）；布尔：启用=绿色"是"、禁用=灰"否"。
6. **状态色语义**：成功/通过/已上架/已完成=绿；警告/待审/处理中=黄或蓝；失败/驳回/取消=红；草稿/停用/过期=灰；信息类=蓝。同一状态全站同色。
7. **渠道圆点色板**【补全】：商城=蓝 `#1a56db`；代言人A=紫 `#7c3aed`；代言人B=青 `#0d9488`；其他按序分配（紫/青/橙 `#ea580c`/粉 `#db2777`/棕），列表与筛选下拉同源映射。

## 8. 交互与反馈规范

### 8.1 反馈决策表【补全】
| 场景 | 用哪种反馈 |
|---|---|
| 写操作成功（保存/删除/上下架/审批） | Toast.success（3s） |
| 表单校验失败 | 字段内联 ErrorText（不弹 Toast） |
| 破坏性操作（删除/取消订单/永久删除/导出/批量） | ConfirmDialog（danger）或 Popconfirm |
| 高危二次确认（回收站永久删除） | 连续两次 ConfirmDialog（现状保留） |
| 长任务（上传/导入/导出/任务） | 进度条/StepModal/任务页轮询 |
| 请求失败 | 列表级 ErrorState + 重试；操作级 Toast.error |
| 会话过期（401） | ReauthModal（重新登录） |
| 渲染异常 | ErrorBoundary 卡片 |

### 8.2 键盘快捷键总表【补全】
| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + K` | 聚焦全局搜索 |
| `Esc` | 关闭最上层弹窗/抽屉/下拉/搜索 |
| `Ctrl/Cmd + S` | 表单页保存当前草稿 |
| `C` | 列表页新建（商品/券/组） |
| `Enter` | 搜索/确认/步骤条下一步 |
| `↑/↓` | 搜索结果选择；表格行导航 |
| `Shift + 点击行复选框` | 区间选择 |
| `?` | 打开快捷键帮助浮层 |

### 8.3 焦点与 Esc 行为【补全】
- 弹窗/抽屉打开：焦点移入（首个可聚焦元素或关闭按钮）；关闭：还原至触发元素。
- 弹窗内焦点陷阱（Tab 循环，不逃逸至背景）；遮罩区不抢焦点。
- 全局 `:focus-visible` 焦点环（键盘操作可见、鼠标点击不显示）。

### 8.4 乐观更新与回滚【补全】
- 高频低风险（标记已读/消息发送/启停）：乐观更新，失败回滚 + Toast.error。
- 中高风险（保存表单/审核/发货）：等待响应，按钮 loading，成功后局部刷新。

### 8.5 列表稳定性【原需求】
- 列表区域固定高度 + 内部滚动；筛选/分页/Tab 变化仅刷新内容；保持滚动位置（条件变化时按场景重置：翻页保持顶部、Tab 切换保持筛选）。

## 9. 无障碍 A11y【补全——原需求完全未提及，大厂标配】

1. **语义化**：真实 button/a/input 标签；表格用 th/scope；图标按钮带 `aria-label`。
2. **ARIA**：Modal/Drawer 用 `role="dialog" aria-modal="true"` + `aria-labelledby`；Toast `role="status"`/`role="alert"`；错误 `aria-describedby` 关联；菜单用 `aria-expanded`。
3. **键盘可达**：全部交互可 Tab/Enter/Space 完成；弹窗焦点陷阱；Esc 体系（§8.3）。
4. **对比度**：正文 ≥4.5:1（现有 muted #767676 达标，禁用态除外）；状态色文字用深色版（如成功用 `#047857` 而非浅底上的亮绿）。
5. **reduced-motion**：`prefers-reduced-motion` 时关闭 shimmer/滑入/缩放动画。
6. **焦点可见**：全局 focus-visible 焦点环。
7. 触控目标：≥24px 命中区（按钮/图标）。

## 11. 性能规范【补全】

- 路由级懒加载（现状）；组件按需加载（抽屉/弹窗内容 lazy）。

## 13. 技术实现与兼容性【补全】
