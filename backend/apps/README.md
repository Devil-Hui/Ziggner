# Ziggner Apps

| 应用 | 功能 |
|------|------|
| `users` | 注册/登录/JWT |
| `goods` | SPU/SKU/分类/品牌/标签 |
| `order` | 订单 |
| `payment` | 支付宝/PayPal 支付 |
| `customer_service` | WebSocket 客服聊天 |
| `notification` | 通知/操作日志 |
| `cart` | 购物车 |
| `promotion` | 优惠券/活动 |
| `review` | 商品评价 |
| `address` | 收货地址 |
| `lovegoods` | 商品收藏 |
| `support` | 用户咨询 |
| `tracking` | 浏览历史 |
| `logistics` | 物流配置 |
| `health` | 健康检查 |

> 新建: `cd apps && python ../manage.py startapp myapp && 在 settings.py 注册`
